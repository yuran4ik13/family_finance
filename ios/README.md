# Family Finance — iOS app (SwiftUI)

Нативна програма для iPhone, яка робить те саме, що й сайт: картки й баланси,
транзакції з пошуком і фільтрами, зміна категорії, правила для мерчантів,
аналітика з графіками, синхронізація з Monobank, налаштування й безпека.

## Два режими

| Режим | Звідки дані | Коли використовувати |
|---|---|---|
| **Demo** | Вигадані дані всередині програми (`DemoData.swift`), працює без інтернету і без бекенду | Показати програму, робити дизайн, скріншоти для портфоліо |
| **Server** | Твій бекенд (`/api/...`) з логіном і паролем | Реальна робота з власними даними |

На екрані входу: **Try with demo data** — демо; іконка сервера вгорі — адреса бекенду.

## Як запустити

1. Відкрий `ios/FamilyFinance.xcodeproj` у Xcode.
2. Вгорі вибери симулятор (наприклад, iPhone 17) і натисни ▶︎ (`Cmd + R`).
3. Натисни **Try with demo data** — і все працює.

Для режиму Server:

- запусти бекенд (`cd backend && npm run dev`);
- у симуляторі адреса `http://localhost:3000` (стоїть за замовчуванням);
- на справжньому iPhone в тій самій Wi-Fi: `http://IP-ТВОГО-MAC:3000`;
- сервер в інтернеті — тільки `https://...` (iOS не дозволяє http поза домашньою мережею).

## Структура

```
FamilyFinance/
├── MyApp.swift              точка входу (як main.tsx у React)
├── App/AppModel.swift       "мозок": хто увійшов, дані, дії (як глобальний state)
├── Models/                  структури даних = JSON, який віддає бекенд
├── Services/
│   ├── FinanceService.swift протокол: все, що програма вміє просити
│   ├── APIClient.swift      реалізація для справжнього сервера (URLSession)
│   ├── DemoService.swift    реалізація з вигаданими даними
│   ├── DemoData.swift       генератор демо-транзакцій
│   ├── ReportBuilder.swift  звіти для демо (та сама логіка, що на бекенді)
│   ├── KeychainStore.swift  безпечне сховище сесії
│   └── BiometricAuth.swift  Face ID
├── Support/                 кольори, іконки категорій, форматування дат і чисел
└── Views/                   екрани
    ├── RootView.swift       що показати: вхід чи програму + Face ID блокування
    ├── Auth/LoginView.swift вхід, реєстрація, адреса сервера
    ├── Main/                Home, Transactions, Analytics, деталі транзакції
    ├── More/                рахунки, категорії, правила, налаштування
    └── Components/          маленькі однакові шматки (картка, рядок транзакції…)
```

Головна ідея: екрани знають тільки протокол `FinanceService`. Тому той самий
екран працює і з демо-даними, і з сервером — треба лише підставити іншу
реалізацію. Так само зробимо і Android-версію.

## Безпека

- Сесія (`ff_session`) зберігається в **Keychain**, а не в UserDefaults, і
  прив'язана до адреси сервера. Не синхронізується в iCloud і не потрапляє в бекапи
  на інші пристрої (`WhenUnlockedThisDeviceOnly`).
- `URLSession` без кешу і без спільних cookies — відповіді з фінансами не
  лишаються на диску.
- **Face ID** блокування (Settings → Security) і розмита заставка, коли програма
  в фоні — баланс не видно в перемикачі програм.
- **http** дозволено тільки для localhost і домашньої мережі (`Info.plist`,
  `NSAllowsLocalNetworking`). Для інтернету — тільки https.
- Токен Monobank вводиться в захищене поле, одразу відправляється на сервер
  і ніде в програмі не зберігається.
- Експорт даних пишеться у файл з `completeFileProtection` (зашифрований, поки
  телефон заблокований).
- Демо-режим нічого нікуди не відправляє.

## Вимоги

- Xcode 26 або новіший, iOS 18+.
- Свій Apple ID у Xcode (Settings → Accounts), щоб поставити на свій iPhone.
